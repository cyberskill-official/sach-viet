# Observability

Structured log events from `b2b-quote-core.mjs`: `b2b_organization_created`, `b2b_organization_member_added`, `b2b_selection_list_created`, `b2b_selection_list_item_added`, `b2b_quote_requested`, `b2b_quote_status_changed`, `b2b_quote_prices_set`. Payloads omit session tokens, emails, request bodies, and payment secrets.
