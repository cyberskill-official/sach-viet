## Phase 2 — BUG-01 mobile header (375px)

| Check | Production (pre-fix) | Local fix branch |
|-------|---------------------|------------------|
| scrollWidth vs clientWidth | **519 vs 375** FAIL | **375 vs 375** PASS |
| Guest login visible in header chrome | **Yes** (`display:flex` despite `hidden`) FAIL | **No** PASS |
| Login in hamburger menu | PASS | PASS |
| LuxuryShell `/membership`, `/login` | No overflow PASS | — |

**Root cause:** PR #57 used `hidden sm:inline-flex`, but `@cyberskill/design` `.cs-button` / `.cs-badge` set `display: flex|inline-flex` with higher specificity, defeating Tailwind `.hidden` on xs. Lang toggle, guest badge, register, and login all remained visible.

**Screenshot:** `tmp/post-merge-smoke/mobile-header-375-pr57.png` (production, pre-fix)

**Regression fix:** branch `fix/TASK-UI-005-header-cs-button-hidden` — adds `.sv-header-desktop-only { display: none !important }` under 640px in [`globals.css`](app/web/src/app/globals.css) and applies to header chrome in [`storefront.tsx`](app/web/src/components/storefront.tsx).

**PR:** push succeeded; open manually if automation blocked: https://github.com/cyberskill-official/sach-viet/compare/main...fix/TASK-UI-005-header-cs-button-hidden
